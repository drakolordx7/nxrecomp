# Hyrule Warriors: Age of Calamity

A Windows and Linux port of the Switch version (1.4.1), in progress. It boots, plays its movies and runs its first battle with the 3D scene, characters and HUD. High frame rates work; resolution and ultrawide support and keyboard and mouse controls are being added. There is no release yet.

No game files will be included; you will need your own dump and keys. Not affiliated with Nintendo or Koei Tecmo. See the [main README](../../README.md) for the project.
