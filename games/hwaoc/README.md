# Hyrule Warriors: Age of Calamity

A Windows and Linux port of the Switch version (1.4.1), in progress. It boots, plays its movies and runs its first battle. High frame rates, any resolution including ultrawide, and keyboard and mouse controls are in. There is no release yet.

No game files will be included; you will need your own dump and keys. Not affiliated with Nintendo or Koei Tecmo. See the [main README](../../README.md) for the project.
