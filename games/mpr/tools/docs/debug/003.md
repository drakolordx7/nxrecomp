# 003: tiled size wrong for 3D mip chains (depth block halved in a loop)

**Symptom.** First cross-check of `tegra_tiling` against Ryujinx's generated data: 3 of 332 cases had a different
`tiled_size` (7x5x4, 33x65x4 and 100x37x9 textures with mips and large `gob_blocks_z`), and 13 cases had a different
`tiled_layer_stride`.

**Cause.** `ref/LAYOUT_NOTES.md` (written from reading `SizeCalculator.cs`) said the block depth shrinks with a
`while` loop like the block height. The source has an `if`: the depth block halves at most once per level.
Separately, Ryujinx's `LayerSize` is the untrimmed sum of the level sizes while `TotalSize` has the last 3D level cut
short, so for a single layer the two differ.

**Fix.** `src/tegra_tiling.cpp` halves `gob_blocks_z` with an `if`, keeps an untrimmed running sum for
`tiled_layer_stride`, and the note is corrected. After the fix: 332 of 332 cases, 20,455,125 blocks identical.
