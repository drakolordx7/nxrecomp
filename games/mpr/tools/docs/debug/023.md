# 023: 46 textures were missing from the survey table

**Symptom.** `test_pak` compared 7,037 TXTR entries with `work/survey/textures/txtr_all.tsv` and found 46 entries with no row.

**Cause.** The table was built from files extracted by retrotool, which stops on one asset name containing `?` in `Preload/MPR1/SamusGunMP1.pak` (the survey notes this). The 46 textures of that pak were never extracted, so they are not in the table. The pak reader in `tools/setup` reads the directory itself and decodes all 46 without error.

**Consequence.** The real total is 6,973 distinct TXTR (inventory) and 4,369 distinct ASTC cache keys (4,413 ASTC entries, 44 duplicates across paks), not the 4,369 ASTC textures the survey counted. The test treats rows that are not in the table as a note.
