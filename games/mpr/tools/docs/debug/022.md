# 022: GUI link failed: duplicate manifest

**Symptom.** Linking `mpr_setup` against the real core failed with `lld-link: duplicate resource: type MANIFEST (ID 24)`; the simulated GUI build had linked only because CMake added no manifest there.

**Cause.** `gui/setup.rc` carries the application manifest (Common Controls 6, per-monitor DPI, UTF-8) and the linker embeds its own default manifest at the same resource id.

**Fix.** `target_link_options(mpr_setup PRIVATE /MANIFEST:NO)` in `CMakeLists.txt`.
