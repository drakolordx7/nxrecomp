# 004 Index register equal to the base register in the corpus words

**Symptom.** The host program of the differential test crashed (access violation) in the middle of the run; every later test was reported different.

**Cause.** Corpus words such as `ldr b, [x16, w16, sxtw]` use one register as base and index. The test state gives the base a window address and the index a small value; with one register both cannot hold. The address was random and unmapped.

**Fix.** Such words are excluded from the tests (`index register is the base register`, listed in the generator output); the host wraps each test in a structured exception handler so a host fault is a failed test, not the end of the run.
