# 003 A stale executable hid a failing build in the end-to-end harness

**Symptom.** After a lifter change a test still printed `guest_unimpl ... simd-i3` although the lifter produced code for that instruction.

**Cause.** The generated C++ of that program no longer compiled, so ninja failed for that target; `run_e2e.py` only checked that `run_<case>.exe` existed, and found the one from the previous build.

**Fix.** The harness deletes every `run_*.exe` before building and reports `x64 build failed` for a missing exe. The differential test has the same rule in another form: a test whose generated statement does not compile is replaced by a stub that reports event 8 and is counted as a failure of its shape.
