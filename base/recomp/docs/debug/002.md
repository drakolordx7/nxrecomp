# 002 LSE atomics with acquire and 64-bit size were lifted as prefetch

**Symptom.** `ldadda`, `ldclra`, `swpa`, `ldsmaxa` ... on X registers (about 12 failing tests per shape) did nothing; tier 2 never saw them.

**Cause.** In tier 1 (`lift/a64.py`, single-register loads and stores) `size == 3 and opc == 2` returns a no-op for PRFM. The LSE atomic class with A=1, R=0 and size 3 has the same size / opc bits. The two are told apart by bit 21 and bits 11:10 (an atomic has bit 21 = 1 and bits 11:10 = 00; register-offset PRFM has bits 11:10 = 10).

**Fix.** The PRFM shortcut now requires `not (bit21 and bits[11:10] == 0)`; the atomics fall through to tier 2.
