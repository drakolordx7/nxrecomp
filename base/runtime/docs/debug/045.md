# 045 c[0] storage buffer descriptor offsets are bytes

Symptom: the compute scene wrote nothing. `storage_slot_for` compared the translator's offsets with word offsets (0x44, 0x144, 0xC4).

Cause: results.tsv prints `sb[c0+0x144]` in 32-bit words; the cache reader stores bytes. In bytes the descriptors are at 0x110 (vertex), 0x410 (geometry), 0x510 (fragment), 0x310 (compute) plus 0x10 per binding, which is Wonder's 0x110 + 0x100 * hardware stage + 0x10 * binding.

Fix: the replay maps byte offsets with those bases; the compute scene passes.
