# 012 Test loop never left the minimised state

Symptom: `gfx_scene` hung for several minutes in the minimise case.

Cause: the case minimised the window at frame 20 and restored it at frame 40, counted in rendered frames. While the window is minimised no frame is rendered, so the counter stays at 20 and the restore never ran.

Fix: the hooks count loop passes, not rendered frames (`SceneRunDesc::per_frame` runs on every pass, including the passes where `begin_frame` returned false). The same fix applies to any test that changes window state and waits for it.
