# 073 CNTPCT_EL0 read as 0

**Symptom.** `MRS of system register 0xdf01 (not modelled): returns 0 (in f_7500340a70)` (`nnosGetSystemTick` family).

**Cause.** The lifter sends every counter register to `guest_mrs`; the runtime answered 0, so every tick based timeout, `nn::os::GetSystemTick`, and the thread tick bookkeeping would stand still.

**Fix.** `guest_mrs` answers CNTFRQ_EL0 (0xdf00) with 19.2 MHz and CNTPCT_EL0 / CNTVCT_EL0 (0xdf01 / 0xdf02) with `kernel::system_tick()`, the same clock as svcGetSystemTick.
