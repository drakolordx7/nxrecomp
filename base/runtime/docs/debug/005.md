# 005 Test probes for access violations under clang-cl

Symptom: a null store inside a `__try` block crashed the test process instead of reaching the `__except` handler.

Cause: without `/EHa` clang-cl only models faults at call sites, so a plain store in the `__try` body is not a throwing operation.

Fix: every probe puts the faulting access into a `__declspec(noinline)` function and calls it from the `__try` body (memory, svc_memory and crash tests).
