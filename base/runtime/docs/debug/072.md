# 072 SetHeapSize accepted more memory than the process was told it has

**Symptom.** `CMemory::InitHeap()` (main 0x4fbac) binary-searches the largest heap `nn::os::SetMemoryHeapSize` accepts between 0 and 6 GiB. Our SVC refused anything over 4 GiB, so the game settled on exactly 4 GiB although `GetInfo(TotalMemorySize)` said 0xCD500000 (3.2 GiB).

**Cause.** The kernel semantic is a resource limit: heap + the process's mapped images + kernel overhead must fit the physical memory the process is advertised. The runtime had two unrelated numbers.

**Fix.** `svc_total_memory()` (GetInfo TotalMemorySize, default 0xCD500000, `[memory] app_memory_mb`) is also the ceiling of SetHeapSize together with the module images (counted in UsedMemorySize now) and the 64 MiB overhead. The search converges to about 3.05 GiB.
