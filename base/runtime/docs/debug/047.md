# 047 Importing the game heap as Vulkan memory

Measured before the design was fixed (RTX 3080 and UHD 770, Vulkan 1.3, Windows 11): memory from `MapViewOfFile` views of a pagefile-backed section, 4096-byte aligned, imports with `VK_EXT_external_memory_host` (minImportedHostPointerAlignment 4096). The memory types offered are host visible, coherent and cached; a GPU `vkCmdFillBuffer` into the imported buffer is visible through both views of the section.

Consequence: NVN pools are imported whole; a GPU address is the host address. Pools larger than `maxBufferSize` are clamped (logged); the game's largest pool is not known yet. Imported pages stay pinned until the pool is finalized or the back end shuts down.
