# 015 MapMemory refused a source in the SDK static data

Symptom: `nn::oe::SetupGpuErrorHandler` -> `nn::os::CreateThread` -> `MapAliasStack` aborted: svcMapMemory (dst in the stack region, src inside the sdk module) returned 0xD401.

Cause: `map_memory` accepted only heap memory as the source. The SDK creates the stack of a system worker thread in its own static data (.bss) and maps it with MapMemory, which the console allows for memory in state CodeData.

Fix: the source may also be a range wholly inside one vm block of state kMemCodeData (a loaded module data or bss segment).
