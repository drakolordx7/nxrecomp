# 008 The test glob swallowed the lifted-test programs

Symptom: after `tests/lift/progs/*.cpp` appeared, the normal build failed with `'rt2.h' file not found`: CMake compiled the guest programs and `native_main.cpp` as unit-test sources of `nxrt_tests`.

Cause: `file(GLOB_RECURSE ... tests/*.cpp)` in `CMakeLists.txt`.

Fix: a non-recursive `file(GLOB ... tests/*.cpp)`. Unit-test sources stay directly under `tests/`; `tests/lift/` has its own CMakeLists, `tests/tools/` and `tests/data/` hold no C++ test sources.
