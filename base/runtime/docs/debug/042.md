# 042 The game refuses an NVN API version that is not 55.x with x >= 8

Symptom (found by reading the game, not by running it): `NVNManaged::CDevice::Init` calls `nvnDeviceGetInteger` for API_MAJOR_VERSION and API_MINOR_VERSION and aborts with "NVN API version does not match driver version! Application: 55.8" unless major == 55 and minor >= 8.

Cause: the table of device values came from smo-recomp (53.312) and the practice mod header (53.105), both older.

Fix: the back end reports 55.15 (the value Wonder reports). `nvnDeviceGetInteger` does not look at the device object, since the game also asks before `nvnDeviceInitialize` has bound one.
