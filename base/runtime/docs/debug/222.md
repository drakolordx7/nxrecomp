# 222 The pipeline cache was never written; pipelines were built at the draw every run

Finding while looking at what a title frame waits for: `nvn_pipeline.cpp` loads `pipeline_cache.bin` at the first pipeline and saves it in `pipeline_shutdown()`. A run ends by closing the window or at the boot loop's deadline, both of which end the process with TerminateProcess without shutting the back end down, so the file was never written (no `pipeline_cache.bin` existed in any run folder) and every run compiled every pipeline from scratch. The title has 8 pipelines (12 ms in total on the RTX 3080); a level has thousands.

Changes (`src/gfx/nvn/nvn_prewarm.cpp`, `nvn_pipeline.cpp`):
* A saver thread writes the VkPipelineCache every 2 s while new pipelines have appeared (temporary file plus rename, so a process that ends in the middle keeps the old file). `nvn::backend_flush_caches()` writes it at once; the window-close path calls it.
* Key file (`pipeline_keys.bin`, `[nvn] pipeline_keys`): every pipeline created at a draw is appended with the hashes of its shaders and the rest of the key as bytes. When the game sets the shaders of a program (`nvnProgramSetShaders`, at load time) the recorded keys of exactly that shader set are queued on worker threads, which build them with the loaded cache. The draw takes the finished pipeline, waits for one in flight, or builds it itself when the key is still queued. A key file written by another layout is deleted and started again.
* `build_graphics_pipeline` is the creation without bookkeeping; shader modules and layouts have locks because the workers use them.

Result at the title: first run 8 pipelines created at draws, 8 keys and a 101 KB cache written while the run is still going; second run 8 queued at program creation, 8 built ahead, 8 taken by draws, none waited, none built by a draw (`prewarm so far:` log line; tests `gfx_nvn_prewarm`: key file written and reloaded, switch off, wrong layout ignored, cache saved while running). Gameplay has not been reached, so the effect on a level's thousands of pipelines is not measured; a first run still builds everything at the draw (there is nothing recorded yet).
