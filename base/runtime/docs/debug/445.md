# 445 Gunship engine jets: no offset from the nozzles found

Report (live testing): the jet particles of the gunship in the opening cutscene do not line up with the nozzles.

What was tried (opening cutscene, `work/n4/cutscene*.nxs`, `work/n4/jet_run.nxs`, headless runs with `NXRT_AUDIO_SINK=null`):

| setup | result |
|---|---|
| merged build, frame cap 60, real step (`work/n4/m1cut`, `m2sel`) | flames start at the nozzle exits and the smoke trails behind the ship in every frame checked (frames 5400, 6200, 6400, 6900) |
| merged build, frame cap 240, real step (`work/n4/j240`, 70 shots, one per second) | same; the flames are longer and the smoke is thicker because the particles are updated in real time, but they stay on the nozzles while the ship and camera move fast (`j069.png`) |
| ultrawide window 2560x1080 with a wider field of view (`work/n4/cs9uw`, older build) | no offset between flames and nozzles |
| base build of 2026-10-22 at cap 240 (`work/n4/j240b`) | cutscene timing differs, so frames cannot be paired; no offset seen either |

Not tested: the timeline cannot be paired frame by frame between builds because the game runs on real time (the deterministic virtual clock never got through the title screens with the mash script). The earlier idea of running `CElementGen::Update` in whole 1/60 s ticks was not built: `CElementGen::InternalUpdate` already converts the step to frames (note S11), and the captures above show no offset at 60 or 240 steps per second.

Related fix in the build: note 442, which covers draws of eight vertex shaders that were being dropped. Those draws include the glowing stripes on the engine casings.

Status: not reproduced, so no change was made for it. A screenshot or short clip from the live build (with its display settings from `controls.ini`) is what is needed to go further.
