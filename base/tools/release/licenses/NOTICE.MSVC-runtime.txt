Microsoft Visual C++ runtime: what this release contains and how it is linked

WHAT IS LINKED

mpr.exe, mpr_setup.exe, mpr_setup_cli.exe and the three astcdec DLLs are linked against the
static Visual C++ runtime (the /MT option). The C and C++ runtime code they need is compiled
into each file. None of them imports MSVCP140.dll, VCRUNTIME140.dll, VCRUNTIME140_1.dll or
the api-ms-win-crt-*.dll names, so a player does not need the Visual C++ Redistributable.
The release script (tools\release\make_release.py) reads the import table of every .exe and
.dll it ships and refuses the release if one of those names appears.

WHAT IS SHIPPED

No Microsoft runtime DLL or installer is in the release. The only Microsoft files the
programs load are parts of Windows itself (kernel32, user32, Media Foundation, DXGI and
similar).

THE TERMS

The runtime libraries were linked in by the Visual Studio Build Tools 2026 C++ toolchain and
the Windows SDK, under the Microsoft Software License Terms that come with them.
Redistribution guidance: https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files
Licence terms: https://visualstudio.microsoft.com/license-terms/

If the release is ever changed to link the runtime as DLLs again, check the "REDIST list" of
those terms first and ship the files with the Microsoft terms that apply to them.
