WHAT THE RELEASE CONTAINS

mpr.exe contains the Metroid Prime Remastered v1.0.0 program code translated to native
x64 code. That code and all game data remain the property of Nintendo and Retro Studios.
The game data (models, textures, audio) is not included; the setup tool extracts it from
your own dump.

shader_cache.mprshc contains shaders translated from the game's own shaders.
