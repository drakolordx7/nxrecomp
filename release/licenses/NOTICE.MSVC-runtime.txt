Microsoft Visual C++ runtime: what this release contains and how it is linked

WHAT IS LINKED

mpr.exe uses the Visual C++ runtime as DLL files. It is not linked statically: the runtime
code is not built into mpr.exe. Its import table (the list of DLLs Windows loads when the
program starts) names these runtime files:

  MSVCP140.dll         C++ standard library
  VCRUNTIME140.dll     C runtime support
  VCRUNTIME140_1.dll   C runtime support (additional functions)

mpr.exe also imports the Universal C Runtime through api-ms-win-crt-*.dll names. Those
come with Windows 10 and Windows 11 itself and are not part of this release.

The other binaries in the release use the same runtime DLLs:

  astcdec-avx2-shared.dll, astcdec-sse4.1-shared.dll, astcdec-sse2-shared.dll
      need MSVCP140.dll and VCRUNTIME140.dll (loaded by mpr.exe at run time)
  mpr_setup.exe, mpr_setup_cli.exe
      need MSVCP140.dll, VCRUNTIME140.dll and VCRUNTIME140_1.dll

WHAT IS SHIPPED

No Visual C++ runtime DLL is in the release. The release script
(tools\release\make_release.py) copies only mpr.exe, the three astcdec DLLs, the two setup
tools, the shader pack, the text files, the licences and the font. A player who does not
already have the runtime installed gets a "was not found" error when mpr.exe starts.

WHAT A PLAYER NEEDS

Install the Microsoft Visual C++ Redistributable for Visual Studio 2015-2022 (x64) before
running the release. The player installs it from Microsoft, under Microsoft's own terms:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

THE TERMS

Microsoft says that distribution of the Visual C++ runtime files is limited to licensed
Visual Studio users and is subject to the Microsoft Software License Terms. The files a
developer may pass on are named in the "REDIST list" that the "Distributable Code" section
of those terms refers to:
https://learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution#-distributable-code-files-for-visual-studio-2022

Licence terms: https://visualstudio.microsoft.com/license-terms/
Redistribution guidance: https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files

If the release is ever changed to include these DLLs, check the REDIST list first, and
ship the files with the Microsoft terms that apply to them.
