# S45 tint: suit and arm cannon colour sliders (parked, work in progress)

Goal: optional `[tweaks] suit_color = off | R,G,B` and `gun_color = off | R,G,B`, off by default, live in game with Reset. Recolour the
painted areas of Samus's base colour textures and keep each texel's luminance and detail. Visor glass, glow (ICAN), normal, metal and
reflection maps stay untouched.

Status: research and offline identification only. No runtime code yet, nothing built, nothing checked in game.

## Prior art

Randovania's randomprime (GameCube Prime) rotates the hue of whole suit textures. `src/txtr_conversions.rs` lists the textures per suit
(body albedo and incandescence, low-poly TestAnim suit, left arm, morph ball, spider ball). `huerotate_matrix` is a 3x3 matrix on the
8-bit values, applied to every mip at patch time. Its GameCube ids do not carry over to the Remastered paks, which use UUIDs and PBR materials.

## How the textures were found

`tint_survey.py` in the root repo, branch tint:
- `toc` reads ADIR and STRG of every RomFS pak into `work/run_tint/toc.json` (31,602 assets with types, names and paks).
- `slots MODEL` prints every TXTR a CMDL/SMDL references, with the material data id in front of it (the 8 bytes before the GUID are
  data id + `TXTR`, see retrotool `cmdl.rs` CMaterialData). BCLR = base colour, ICAN = incandescence, NMAP, METL, REFL/REFS/REFV, TCH0/1.
- `walk ROOT` follows GUID references from a model down to its textures.

Models used: the Character Gallery suit CMDLs (`Worlds/FrontEnd/CharacterGallery/01..06`). Their textures live in `Preload/DuplicateData.pak`.

## Planned method (not built)

- Recognise: at startup, read the listed TXTRs from the player's paks with `nxrt_mprpak` (as `games/mpr/mpr_prompts.cpp` does) and keep
  (tiled size, hash). In `prepare_texture`, on ASTC textures with a matching size and hash, call a new game hook.
- Recolour on the CPU: decode the ASTC source to RGBA8 (`a2b_decode_astc_rgba8`), recolour, and encode BC7 at bc7e quality 0-1 (the
  image stays BC7, so `caps.image_format` is unchanged). Never write the result to `bc7_cache`, so the shared cache stays vanilla.
- Mask: no separate paint mask was found in the material slots (only BCLR/ICAN/NMAP/METL/REFL/TCH). Derive one from the vanilla texel:
  weight = smoothstep on saturation, times a hue window around the suit's paint (orange/red for Power and Varia, purple for Gravity,
  black and red for Phazon). The output keeps luminance: out = mix(src, tint × luma(src) / luma(tint), weight).
- Live: when the slider changes, wait 250 ms (debounce), then mark only the matching textures cpu_dirty, similar to
  `textures_mark_override_candidates_dirty`. Cost estimate, not measured: decode, recolour and encode of a 2048² chain, about 0.1 s on
  all threads.
- Settings and UI in the game module's own files (`games/mpr/mpr_tint.*`), with entries in CONFIG.md.
