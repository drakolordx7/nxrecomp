# 005 Capstone drops the post-index immediate of structure loads and stores

**Symptom.** `ld1r`..`ld4r` and single-lane `ld3`/`st3` with post-index by immediate did not advance the base register (1056 tests, 80 shapes).

**Cause.** For these forms Capstone does not report the writeback immediate as an operand (nor always as writeback). The amount always equals the number of bytes transferred.

**Fix.** `x_ldst.py` reads the writeback from the instruction text and checks that the immediate equals the bytes transferred; a register post-index of XZR is the immediate form.
