# 046 vkCmdClearAttachments ignores the colour write mask; copy filter flag

Two findings of the state and texture oracles.

ClearColor with a partial channel mask cleared every channel. vkCmdClearAttachments does not apply the write mask. Fix: `nvn_mask_clear.*` draws a full-screen triangle with the mask as colorWriteMask (floats, ints and uints, scissor = clear rectangle).

CopyTextureToTexture with different sizes used the filter backwards: NVN_COPY_FLAGS_LINEAR_FILTER_BIT (0x1) selected NEAREST. Fixed; the scaled copy case in `gfx_nvn_scene_texture` checks the averaged texels.
