# 041 The translated SPIR-V depends on the code block only

Symptom: the survey keyed shaders by sha1(code + control section): 67,506 blocks. The runtime receives the code block and a control pointer without a length, so it cannot reproduce that hash.

Finding: only 13,016 distinct code blocks exist; 9,750 of them occur with several control sections. For all 9,750 the harness produced byte-identical SPIR-V and identical status and resource lists (`make_code_corpus.py --verify`, run on the unpatched translation of all 67,506 blocks).

Fix: the cache is keyed by the first 16 hex digits of sha1 over the code block (`code_size` bytes at control +0x704). The cache shrinks from 4.0 GB to 1.0 GB and from 67,506 to 13,016 modules.
