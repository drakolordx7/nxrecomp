# 020: ticket rights id read at the wrong offset

**Symptom.** `test_container` failed three ticket checks: a dump whose program NCA is protected by a rights id could not find its title key, so any real eShop NSP would have stopped with "no ticket".

**Cause.** `container.cpp parse_ticket` read the rights id at ticket body +0x15C (written from memory). The Switchbrew ticket page puts it at body +0x160 (file offset 0x2A0 for the usual RSA-2048 ticket, 0x140 + 0x160). The synthetic-dump builder was written independently from the wiki and disagreed; the real `.tik` of the dump confirms 0x160.

**Fix.** Offset changed to 0x160. Real dump: the rights id of the ticket equals the NCA's, the title key decrypts, the ExeFS and RomFS sections open (`test_realdump`).
