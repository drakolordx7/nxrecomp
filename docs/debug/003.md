# 003 sched_reset_for_tests could not retake its processor slot (sched.cpp)

Symptom: none in tests; found when a test worker read `take_slot`.

Cause: the processor slot is claimed through a named mutex (`Local\nxrt_console_cores_<k>`) that stays open for the life of the process. After `sched_reset_for_tests()` the next `sched_info()` saw `ERROR_ALREADY_EXISTS` on the slot it had held itself and moved to the next slot, so the test's host processors changed between resets.

Fix: the reset closes the slot mutex handle.
