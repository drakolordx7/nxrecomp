# 008 Code outside every discovered function was never lifted

**Symptom.** `python .weaver/lift_stats.py` on the game found `.text` bytes that no function covers and that are not padding: 41 pieces in `sdk` (3,196 bytes: the SVC wrappers `sub sp; stp ...; bl ...; svc #n` from 0x750035a4c8, the FPCR / FPSR accessors at 0x7500563450, a 2-instruction self-branch) and 1 in `subsdk0` (32 bytes at 0x7600185800). `cover` still said 100%, because it counts instruction words, not functions.

**Cause.** Discovery takes `.eh_frame` and sized symbols, then `bl`, relocation and tail-call targets. Hand-written assembly stubs have no FDE and no symbol size, and nothing in the module branches to them directly (callers use the function table or a pointer), so they were in no function and `call_indirect` could not find them.

**Fix.** `funcs.analyse` cuts every run of code between two functions after each `ret` / `br` / unconditional `b` and makes each piece that is not only zero words and nops a function with evidence `G`; the NSO header (up to the end of MOD0) is excluded. `main` gains none, `sdk` 41, `subsdk0` 1.
