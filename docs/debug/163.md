# 163 Small facts that cost time

* SDL names the keys `PageUp` and `PageDown` (no space); `Left Ctrl`, `Keypad Enter`, `Return`, `Escape` are as written in the settings file.
* An SDL virtual gamepad's trigger axes cover the full -32768..32767 range, so a rest value of 0 reads as half pulled and presses ZL and ZR. Set them to -32768 for rest (`tests/gfx/test_play_pad_live.cpp`).
* A C++ string `"\result.json"` is a carriage return followed by `esult.json`; use `/` in paths in tests.
* Game offsets for mouse aim and the beam and visor state are listed in docs/S8.md; they were read with `gdis.py` (local test script) from `work/elf/main.elf`.
* The frame limiter keeps its schedule inside the real game (frames that wait start within 0.1 ms), but window mode at the title screen delivers about 49 fps unlimited with 100 to 250 ms stalls, so the average stays under the cap. Headless the same build presents about 97 frames per second.
