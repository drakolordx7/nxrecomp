# 100: Eden window capture is black in an unattended session

**Symptom.** PIL `ImageGrab` raised "screen grab failed", and PrintWindow, BitBlt and desktop copies of the Eden window were all black although Eden ran the game at 20 fps.

**Cause.** The automated session is a disconnected Windows session (`query session` shows the user session as `Disc`), so DWM does not compose windows and there is no input desktop. Not an Eden problem.

**Fix.** Frames come from the LunarG screenshot layer (`VK_LAYER_LUNARG_screenshot`, in the Vulkan SDK `Bin` folder): `VK_INSTANCE_LAYERS`, `VK_LAYER_PATH`, `VK_SCREENSHOT_DIR` and `VK_SCREENSHOT_FRAMES` (a comma list of present numbers). It writes the swapchain image as PPM, with no desktop involved. `tools/test/eden_run.py` sets this up. `wincap.py` stays for interactive sessions.
