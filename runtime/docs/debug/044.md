# 044 Window origin and viewport: what the two modes mean

Symptom: the first geometry oracle asserted that upper-left and lower-left origin mirror the picture. With the first viewport code they did not.

Cause: the replay converted only the y coordinate of viewport and scissor, and kept NDC +y at the top in both modes.

Rule now implemented: upper-left: window y is the image row from the top, NDC +y is the top edge of the rectangle (negative-height viewport), front face kept. Lower-left (GL convention): window y 0 is memory row 0 and NDC -y is the first row (positive height, no flip), front face inverted. The game sets upper-left. `gfx_nvn_scene_geometry.origin_*` pins both.
