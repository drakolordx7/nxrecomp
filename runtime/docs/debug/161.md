# 161 Scripted runs crash at start (svcBreak) without a RomFS path

`run_suite.py` does not set `NXRT_FS_ROMFS` and `NXRT_FS_SAVE_DIR` (boot.py does). Without them the game aborts about one second in with a guest `svcBreak`, also with the old release exe, so it is not a play-mode problem. `tools/test/suites/play.toml` sets both (`../../game/romfs`, `save`, relative to `work/run`). In deterministic mode the title screen stops animating, so frames 1300 and 1900 give stable pictures; at frame 450 the game is still on the Nintendo and Retro Studios logo.
