# 040 PIXLD left unimplemented in the shader translator

Symptom: "Shader instruction Pixld is not implemented" in 33,361 of 33,744 pixel blocks of the game (98.9 %).

Cause: Ryujinx decodes PIXLD and does not write the destination register, so the SPIR-V reads an undefined value. The mode in every block is MY_INDEX (PixMode 5), the sample index; its first use in the shaders that read it is the first term of a byte-table index into `c[0] + 0x620` (a sample and pixel keyed dither table).

Fix: patches in `tools/shaders/harness/translator/spirv-pixld-*.patch` add `IoVariable.SampleId` and make PIXLD.MY_INDEX read `gl_SampleID` (SampleRateShading capability); other modes write 0 and log. After the patch no block reports the message and all 67,506 blocks still validate. The `c[0]` table contents are unknown; the back end binds zeros.
