# 043 gl_PerVertex exceeds maxCombinedClipAndCullDistances

Symptom: validation error VUID-RuntimeSpirv-maxCombinedClipAndCullDistances-00710 when creating the first pipeline of any translated vertex shader: ClipDistance[8] plus CullDistance[1] is 9, the limit is 8 on NVIDIA and Intel.

Cause: Ryujinx declares the GL sized gl_PerVertex block in every vertex-pipeline module.

Fix: the translator build declares ClipDistance[7] (patch spirv-pixld-declarations-spirv.patch). No shader of the game writes clip distance 7.
